# BEFAST Privacy Policy — GitHub Pages

## Publish using GitHub Pages

1. Create a new **public** GitHub repository, for example `befast-privacy-policy`.
2. Upload `index.html` and `data-deletion.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. The URLs should look like:
   - `https://YOUR-GITHUB-USERNAME.github.io/befast-privacy-policy/`
   - `https://YOUR-GITHUB-USERNAME.github.io/befast-privacy-policy/data-deletion.html`
7. Open both URLs in a private/incognito window and confirm they load publicly.

## Meta app settings

In Meta for Developers → App settings → Basic:
- Privacy Policy URL: the published `index.html` URL
- User Data Deletion: choose the URL option and enter the published `data-deletion.html` URL

The content is a starting template. Confirm it accurately describes your actual data handling before publishing.
